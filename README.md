# Blaze Kitchen

A full-stack cloud kitchen web application designed to provide a modern online food-ordering experience with menu management, authentication, cart and checkout, order management, and an administrative dashboard.

##  Features

-  User registration and login
-  Dynamic food menu and category filtering
-  Shopping cart and checkout
-  Order placement and order management
-  Admin dashboard
-  Menu and category management
-  Real-time order updates
-  Dashboard analytics
-  JWT-based authentication
-  MongoDB database integration
-  API and frontend-backend integration testing
-  Responsive user interface
-  Light/Dark theme support
