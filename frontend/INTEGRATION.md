## Backend Setup (Node.js)
npm install express mongoose jsonwebtoken bcryptjs cors dotenv nodemailer razorpay socket.io passport passport-google-oauth20 web-push

## .env Variables
MONGODB_URI=mongodb://localhost:27017/blaze-kitchen
JWT_SECRET=your-secret-key
GOOGLE_CLIENT_ID=your-google-client-id
RAZORPAY_KEY_ID=your-razorpay-key
EMAIL_USER=your-email@gmail.com
EMAIL_PASS=your-gmail-app-password
